# Customer dictionary

We need a customer dictionary, where we can store our customer information. We need a screen where we can see the customers in a list, add new customer, edit customer, delete customer, the deletion should be logical not fisical.

## Table definition

|column|data type|nullable|comments|
|------|---------|--------|---------|
|id|int|false|pk and autoincrement|
|name|nvarchar(255)|false||
|Address|nvarchar(255)|false||
|RFC|nvarchar(25)|false||
